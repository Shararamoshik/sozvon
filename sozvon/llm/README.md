# Адаптер отчёта

Публичный вход: `sozvon.llm.provider.generate(payload, stop_event, emit) -> dict`.
Схема payload и результата — `docs/CONTRACT.md`. Значения по умолчанию: пустые
`api_key`/`title`, `timeout=120`, `template="meeting"`, `language="ru"`.
Неверный вход/непроверяемые цитаты дают безопасный `ValueError`, ошибки транспорта,
ответа и отмена — `RuntimeError` с русским сообщением без тела ответа и ключей.

## Сеть и стоимость

- Ровно один POST: OpenAI `<base_url>/chat/completions`, Anthropic
  `<base_url>/v1/messages`. Для Anthropic указывайте базу **без** `/v1/messages`
  и без отдельного `/v1`, например `https://api.anthropic.com`.
- HTTPS для удалённых адресов; HTTP только буквальный loopback IP или `localhost`.
  HTTP `localhost` закрепляется за `127.0.0.1` без DNS; для IPv6-only используйте
  `http://[::1]:порт`. Userinfo, query, fragment и неоднозначные URL отклоняются.
- `trust_env=False`, `follow_redirects=False`, проверка TLS включена по умолчанию.
  Нет endpoint probe, retries, fallback модели или repair-запроса. Тела HTTP-ошибок
  не читаются. Разрешение удалённой передачи в UI проверяет вызывающий сервис.
- Лимит прототипа: **64 000 байт UTF-8** для полного сериализованного пользовательского
  контекста (title/template/language/segments, включая метаданные сегментов).
  Превышение отвергается **до запроса**, ничего не обрезается.
- Выход: `max_tokens=4096`, максимум **512 000 байт** ответа API. Неполный ответ
  (`length`/`max_tokens`) считается ошибкой. Старые/особые OpenAI-совместимые серверы,
  не принимающие `response_format=json_object` или `max_tokens`, возвращают понятную
  HTTP-ошибку; автоматического платного «исправления совместимости» нет.
- Отмена проверяется до отправки, при чтении ответа и до возврата. Зависшее сетевое
  чтение прерывает таймаут httpx или supervisor worker-процесса; адаптер не создаёт
  фоновый запрос, который продолжит работу после отмены.

## Что проверяется

Все разделы обязательны; каждый пункт содержит хотя бы одну цитату. `owner` и
`due` обязательны как ключи, но могут быть `null`. Лишние поля, включая `sources`,
пустой отчёт, неверный JSON, повторяющиеся JSON-ключи и невалидный Unicode отклоняются.
ID — точная строка либо целое число, без преобразования `"1"` в `1`. Цитата должна
встречаться в тексте **своего** существующего сегмента; Unicode-пробелы при сравнении
схлопываются, буквы, регистр и пунктуация не исправляются. Цитаты не переписываются.

Это проверка происхождения цитаты, **не доказательство смыслового следования**:
правильная цитата сама по себе не гарантирует правильность вывода, назначения
исполнителя или срока. Человек должен проверить отчёт перед использованием.
`usage` необязателен: наружу проходят только известные неотрицательные целочисленные
счётчики токенов; прочие поля провайдера не отражаются. Markdown здесь не рендерится.

## Проверка без внешних запросов

```sh
.venv/bin/python -m pytest tests/test_llm*.py
.venv/bin/ruff check sozvon/llm tests/test_llm*.py
```

Все HTTP-вызовы в тестах перехватываются `httpx.MockTransport`; настоящие модели,
учётные данные, сетевые подключения и платные вызовы не нужны.
