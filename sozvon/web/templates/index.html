ПОД ВАШ РАБОЧИЙ ПРОЦЕСС

Настройки

Модель для отчёта

Совместимый API, локальный или удалённый. Соединение используется только по команде «Создать отчёт».

Один запуск — один запрос к модели. Удалённый провайдер может списать средства; длинные расшифровки пока ограничены.

Распознавание речи

Распознавание работает на устройстве. Модель нужно подготовить отдельно — приложение не скачивает её автоматически. В технической версии распознаются записи до 30 минут.

Источники звука

Микрофон и системный звук сохраняются отдельными дорожками. Системный звук требует WASAPI в Windows.

Новая запись

Сохранение не запускает модель.

После загрузки запустите распознавание отдельно. Путь к локальной модели задаётся в настройках.

Запись на этом устройстве

Приложение записывает звук компьютера, на котором запущено. После остановки дорожки появятся в источниках.

Устройства выбираются в разделе «Настройки → Запись».
