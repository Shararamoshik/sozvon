# Созвон

Независимое локальное приложение для созвонов. Техническая версия, отдельный репозиторий и данные.
Не требует и не импортирует существующий проект «Протокол».

## Запуск на Windows

Открыть `D:\sozvon\scripts\start.bat` либо `D:\sozvon\dist-v02\Sozvon\Sozvon.exe`.
Весь каталог `dist-v02/Sozvon` должен оставаться вместе с `_internal`; отдельный EXE не переносим.
Прежняя сборка сохранена в `dist/Sozvon`; `start.bat` предпочитает новую 0.2.
Для остановки — Ctrl+C в его консоли. При уже запущенном экземпляре используйте его вкладку.

В настройках распознавания для первой проверки можно указать
`D:\sozvon\artifacts\models\tiny`. Это отдельно загруженная проверочная модель.
Адрес и модель LLM задаются пользователем; никаких ключей из других проектов не перенесено.

## Разработка

```sh
uv sync --frozen --extra dev --extra build
uv run python -m sozvon
uv run pytest
uv run ruff check sozvon tests
```

Сервер слушает только 127.0.0.1; по умолчанию порт 8098. Одноразовая ссылка открывает локальную
сессию, данные требуют авторизацию. Ключи LLM и облачного STT — в отдельных профилях системного хранилища, не в TOML.
Закрытие вкладки не завершает процесс; в этой технической версии выход — Ctrl+C в консоли.

## Возможности 0.2

Библиотека, импорт текста/аудио, локальное и OpenAI-совместимое облачное распознавание,
структурированный отчёт через API, заметки, Markdown/JSON/DOCX/PDF, два источника записи на Windows.

- В «Настройки → Распознавание» выберите компьютер или API. Для облака задайте базовый адрес,
  модель, формат ответа и отдельный ключ STT. Отправка аудио подтверждается для каждой операции;
  скрытых повторных платных запросов нет. Совместимость чат-API не означает поддержку STT.
- В «Настройки → Отчёт» задаются лимит ответа (256–65536 токенов, по умолчанию 16384)
  и ожидание API (10–600 секунд, по умолчанию 300). У reasoning-моделей бюджет может
  включать рассуждения и итоговый JSON; увеличение лимита может увеличить стоимость.
  Лимит модели/провайдера имеет приоритет. Старые настройки без этих полей получают
  новые значения по умолчанию; сохранённые значения не подменяются при смене модели.
  При обрыве, фильтрации или отказе отображается конкретная безопасная причина;
  незавершённый отчёт не сохраняется, повтор возможен только вручную.
- Во вкладке «Расшифровка» можно править текст и говорящего, искать и заменять фразы,
  просматривать историю и восстанавливать версию. Таймкоды и порядок реплик не меняются.
  Восстановление создаёт новую версию; конфликт двух вкладок не затирает черновик.
- Встроенные шаблоны: «Рабочая встреча», «Встреча с клиентом», «Техническое обсуждение»
  и компактное «Собеседование» — итог по кандидату, вердикт и договорённости, рекомендации,
  следующие шаги, не выяснено, пробелы и риски. Объём ответа задаёт подробность шаблона:
  кратко — 3–5 пунктов на раздел, обычная — 6–8, подробная — с деталями и пояснениями;
  инструкции разделов тоже уходят модели. Недостающие встроенные шаблоны добавляются
  в существующую базу при запуске: пользовательские шаблоны, записи и ключи не меняются.
- В разделе «Шаблоны» создаются собственные структуры отчёта: названия, порядок,
  дополнительные разделы, подробность, язык и инструкции. Встроенный шаблон редактируется
  через копию. Шаблон по умолчанию выбирается в настройках отчёта.
- «Экспортировать» сохраняет отчёт или расшифровку в DOCX/PDF/Markdown без Office
  и без вызова модели. PDF содержит встроенный кириллический шрифт и выделяемый текст.
  JSON — полный архив с историей. Устаревший отчёт нужно пересоздать; экспорт новой
  расшифровки остаётся доступен. Если символ отсутствует во встроенном шрифте PDF,
  приложение откажет с его кодом Unicode и предложит DOCX, а не потеряет символ молча.
Никаких вымышленных результатов модели: без подключения отчёт не создаётся.

Не являются готовыми возможностями: автоматическое восстановление фрагментов записи,
полная очередь нескольких задач, диаризация, словарь, SRT, монтаж реплик, установщик,
незаметное фоновое обновление и автономная LLM внутри дистрибутива.
Сейчас одна операция распознавания/отчёта/записи одновременно и один экспорт.
Незаконченная задача после запуска явно прервана. Перед миграцией старой непустой БД
создаётся резервная копия в каталоге данных `backups/`.

## Модель

Распознавание не скачивает модель неявно. В настройках указывается существующая папка модели
CTranslate2. Для проверок используется отдельно загруженная tiny в artifacts/models/tiny.
Это тестовый профиль, не обещание качества для всех встреч. GPU не обязателен.
Распознавание в текущей версии ограничено 30 минутами на запись; более длинное аудио
можно сохранить, но перед STT нужно разделить отдельно. Отчёт ограничен 64 000 байтами
входного контекста, без скрытого обрезания.

## Проверки

Точные результаты и ограничения после интеграции фиксируются в docs/VERIFICATION.md.
Контракты: docs/CONTRACT.md и расширение docs/FEATURES-V02.md.
Сквозная проверка на синтетических loopback-сервисах: `python scripts/check_frozen_features.py`;
для собранного приложения — дополнительно `--exe <путь-к-Sozvon.exe>`. Она использует отдельный
каталог в `artifacts/` и не отправляет пользовательские записи.
