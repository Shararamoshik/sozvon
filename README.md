# Созвон

Независимое локальное приложение для созвонов. Техническая версия, отдельный репозиторий и данные.
Не требует и не импортирует существующий проект «Протокол».

## Запуск на Windows

Открыть `D:\sozvon\scripts\start.bat` либо `D:\sozvon\dist\Sozvon\Sozvon.exe`.
Весь каталог `dist/Sozvon` должен оставаться вместе с `_internal`; отдельный EXE не переносим.
Для остановки — Ctrl+C в его консоли. При уже запущенном экземпляре используйте его вкладку.

В настройках распознавания для первой проверки можно указать
`D:\sozvon\artifacts\models\tiny`. Это отдельно загруженная проверочная модель.
Адрес и модель LLM задаются пользователем; никаких ключей из других проектов не перенесено.

## Разработка

```sh
uv sync --frozen --extra dev --extra build
uv run python -m sozvon
uv run pytest
uv run ruff check sozvon tests
```

Сервер слушает только 127.0.0.1; по умолчанию порт 8098. Одноразовая ссылка открывает локальную
сессию, данные требуют авторизацию. Ключи LLM — в системном хранилище, не в TOML.
Закрытие вкладки не завершает процесс; в этой технической версии выход — Ctrl+C в консоли.

## Границы первого этапа

Библиотека, импорт текста/аудио, локальный STT из установленной папки, структурированный отчёт
через совместимый API, заметки, Markdown/JSON, два источника записи на Windows.
Никаких вымышленных результатов модели: без подключения отчёт не создаётся.

Не являются готовыми возможностями: автоматическое восстановление фрагментов записи,
полная очередь нескольких задач, диаризация, редактор шаблонов, словарь, DOCX/SRT, установщик,
незаметное фоновое обновление и автономная LLM внутри дистрибутива.
Сейчас одна длительная операция одновременно, незаконченная задача после запуска явно прервана.

## Модель

Распознавание не скачивает модель неявно. В настройках указывается существующая папка модели
CTranslate2. Для проверок используется отдельно загруженная tiny в artifacts/models/tiny.
Это тестовый профиль, не обещание качества для всех встреч. GPU не обязателен.
Распознавание в текущей версии ограничено 30 минутами на запись; более длинное аудио
можно сохранить, но перед STT нужно разделить отдельно. Отчёт ограничен 64 000 байтами
входного контекста, без скрытого обрезания.
