# Что не удалось подтвердить автоматически

Статусы: `не подтверждено` — данные не найдены в доступных источниках; `ручная проверка` — нужен
доступ, которого нет из WSL (проверяет пользователь).

## 1. Реестр российского ПО — ручная проверка

`reestr.digital.gov.ru` недоступен из этой сети (HTTP 000, соединение не устанавливается).
Проверить вручную: https://reestr.digital.gov.ru/reestr/ — поиск по словам «протокол», «расшифровка»,
«совещание». Зафиксировать: число записей, 2–3 примера (название, правообладатель, дата).
До проверки число решений в реестре в исследовании не используется.

## 2. Закупки — ручная проверка

`zakupki.gov.ru` недоступен из этой сети (HTTP 000).
Проверить вручную: https://zakupki.gov.ru — расширенный поиск, запросы «расшифровка аудио»,
«протокол совещания», «стенограмма», период 2025–2026. Сохранить 3–5 карточек (номер закупки,
заказчик, предмет, сумма, дата). До проверки объём закупок в исследовании не оценивается.

## 3. Число организаций для TAM — не подтверждено

`fedstat.ru` (ЕМИСС) отдаёт 403 на автоматические запросы; официальные публикации Росстата
не дали машиночитаемого значения. Величина SAM (300 организаций) остаётся допущением команды
с явной пометкой. Если число появится — заменить в `data/inputs.json` значение
`org_count_industrial`, поменять `label` на `source`, указать URL и цитату, затем пересобрать
диаграммы и досье.

## 4. Позиции конкурентов на карте — экспертная оценка

Координаты компаний на карте (`competitors` в `data/inputs.json`) — оценка по публичным функциям
их страниц, а не измерение. Подпись об этом обязательна на самой диаграмме.
