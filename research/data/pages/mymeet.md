Что ловит:
upload_file_selected — файл выбран через диалог
upload_file_dropped — файл брошен в дропзону
upload_started — начало загрузки (ОДИН раз на файл, а не на каждый чанк)
upload_success — файл загружен целиком (последний чанк, 2xx) + meeting_id
upload_failed — ошибка загрузки (код ответа + номер чанка)
transcript_ready — НОВОЕ: транскрипт отдан пользователю (GET /api/video/report → 200)
transcript_copied — НОВОЕ: клик по «Скопировать» (navigator.clipboard.writeText)
transcript_downloaded — НОВОЕ: скачивание файла (window.open → /api/storage/download), с форматом
guest_open_app — НЕОБЯЗАТЕЛЬНО: клик по «Открыть в mymeet.ai» / «Загрузить ещё»
Все цели в Метрике заводятся как «JavaScript-событие» с идентификатором = имя выше.
