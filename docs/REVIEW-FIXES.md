# Исправления независимой проверки

Проверка выявила реальные стыки, которых не было в первоначальных тестах. Этот файл не
подменяет итоговый прогон; статусы ниже подтверждаются соответствующими регрессиями.

- Нельзя смешать endpoint из старой конфигурации и новый ключ: атомарный снимок настроек/ключа,
  общий lock сценария запуска и сохранения настроек.
- Идентификатор ревизии отчёта передаётся от входного снимка, а не вычисляется в конце.
- Занятость проверяется до чтения текста для следующей обработки.
- Итоговая длительность берётся из целого результата записи, не из последней дорожки.
- Предупреждения capture сохраняются в состоянии записи и остаются в интерфейсе.
- Устаревший отчёт обозначается в UI, переход в новый текст отключён, Markdown требует актуальной версии.
- Недоступное системное хранилище не равно отсутствующему ключу и не подтверждает удаление.
- Разделы настроек проверяются на тип до merge.
- Остановка CLI через Ctrl+C не печатает трассировку штатного завершения.

Исправлены аудиограницы: ошибка active возвращает подтверждённые WAV; задержка старта
компенсируется нулевыми кадрами, UNC/сетевые диски отвергаются до обращения к целевому пути.
Результат STT ограничен размером IPC без обрезки, длительность STT — 30 минут.
Синхронизация независимых аппаратных часов на долгих записях остаётся ограничением.
Финальный результат — в VERIFICATION.md.
